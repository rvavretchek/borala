# Contexto persistente do projeto Bora Lá

## Idioma da documentação

- Toda comunicação, documentação, requisito, épico, história e critério de aceitação deve ser escrita em Português do Brasil.
- Critérios de aceitação no formato BDD usam obrigatoriamente `Dado`, `Quando`, `Então` e `E` — nunca `Given`, `When`, `Then` ou `And`.
- Nomes de arquivos e identificadores de código permanecem em inglês, conforme a Constituição.
